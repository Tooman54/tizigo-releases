## Android

Для большинства телефонов подходит кнопка **Android APK** выше. Если архитектура устройства неизвестна, скачайте [универсальный APK](https://github.com/Tooman54/tizigo-releases/releases/download/downloads-2026-11-05/TiziGo-1.30.9-play-universal.apk).

APK устанавливается напрямую. Google Play для скачивания и установки не требуется. Подпись VelikSoft совместима с прежними APK с этой страницы. У версии из Google Play другая подпись; при несовпадении подписи сохраните установленное приложение и его данные. Покупки через Google Play требуют работающего магазина.

## Windows

Скачайте EXE по кнопке **Windows x64** и запустите установщик. Включены последние исправления регионов, подписки и VPN-ядра. Номер остался 189, эта сборка содержит обновления от 03.11.2026.

Установщик пока без цифровой подписи издателя. Для VPN нужны права администратора.

## macOS

Скачайте ZIP по кнопке **macOS**, распакуйте его и перенесите TiziGo в «Программы». Один пакет подходит для Intel и Apple Silicon. Приложение подписано Developer ID и прошло нотариализацию Apple.
